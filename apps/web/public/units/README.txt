Unit art goes here as transparent PNGs, one per unit, named exactly:

  infantry.png  artillery.png  light_tank.png  heavy_tank.png
  fighter.png  bomber.png  air_support.png
  submarine.png  destroyer.png  cruiser.png  battleship.png

If you only have one tank image, name it tank.png and it is used for both tanks.
Missing files fall back to the built-in drawn figures, so you can add them one at a time.
Same camera angle, lighting and proportions for every unit; no text in the image.
Square-ish crops around 256-512 px on the long side work well (they are shown at 20-40 px).


INCLUDED: all 11 unit images are already in this folder (cut out of the supplied JPGs, 640 px long side).
To replace one, drop a transparent PNG with the same file name here.
